USE CASES

What people actually use it for.

▶

Analyze competitor content

/watch https://youtu.be/... what hook did they open with?

The agent watches the first frames, reads the opening transcript, breaks down the structure. Ad creative, competitor launches, podcast intros — any video where how matters as much as what.

◎

Diagnose a bug from a recording

/watch bug-repro.mov what's going wrong?

Someone sends a screen recording. The agent finds the frame where the issue appears, describes what's on screen, often catches the cause without you ever opening the file.

⊘

Cut the hype from a launch video

/watch https://youtu.be/... what's actually new — skip the hype

Strip a “game-changer” feature drop down to the few things that matter. Substance without ten minutes of intro and overselling.

≡

Turn a playlist into notes

/watch https://youtu.be/... summarize this to a note

Run it across a course or series. A channel becomes a searchable set of timestamped notes instead of hours you have to sit through.

HOW IT WORKS

Seven steps. The agent does all of them.

01

You paste a video and a question.

URL (anything yt-dlp supports — YouTube, Loom, TikTok, X, Instagram, 400+ more) or a local path (.mp4, .mov, .mkv, .webm).

02

yt-dlp checks captions first.

At transcript detail, captioned URLs return without downloading video at all. Otherwise downloads only what the run needs.

03

ffmpeg extracts frames at the chosen detail.

efficient decodes keyframes only (~0.5s). balanced uses scene-change detection. JPEGs are 512px wide, clamped for agent vision compatibility.

04

Deduplication drops near-identical frames.

A 16×16 pixel brightness-delta pass drops frames visually identical to the last kept one. A slide held for 90 seconds collapses to one frame. Budget spent on distinct content.

05

Transcript from captions or Whisper.

First try: native captions — free, instant. Fallback: extract mono 16kHz audio (~480kB/min) and send to Groq whisper-large-v3 (preferred) or OpenAI whisper-1.

06

Frames + transcript handed to the agent.

Frame paths with t=MM:SS markers and a timestamped transcript. The agent reads each frame as an image in parallel.

07

The agent answers grounded in what's on screen.

Not “based on the description.” It saw the frames. It heard the transcript. It answers the way someone who watched the video would.

WHAT YOU NEED

Captions are free. Whisper is cheap.

Captions cover most public videos. Whisper only kicks in when there are genuinely no captions — local files, TikToks, some Vimeos.

CapabilityWhat you needCost
Download + native captionsyt-dlp + ffmpegFree
Whisper fallback (preferred)Groq API key — whisper-large-v3Cheap, fast
Whisper fallback (alt)OpenAI API key — whisper-1Standard pricing
Disable Whisper entirely--no-whisperFree — frames only
◎
First run setup is automatic. On the first /watch call, the skill checks for ffmpeg and yt-dlp. macOS auto-runs brew install ffmpeg yt-dlp. Linux and Windows print exact commands. After that, preflight is silent — sub-100ms on every run.
