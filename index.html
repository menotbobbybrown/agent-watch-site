How it works

Seven steps. The agent does all of them.

An automated pipeline optimized for context window efficiency and speed.

1

Paste a video URL or local path

Provide anything yt-dlp supports (YouTube, Loom, X, etc.) or a local `.mp4`, `.mov`, `.webm` file.

2

yt-dlp checks captions first

Instant text extraction if captions exist. Downloads video only if visual frames are requested.

3

ffmpeg extracts frames

Extracts at the chosen detail level (efficient keyframes vs balanced scene detection).

4

Deduplication engine

Collapses near-identical frames (e.g. a 90-second static slide becomes 1 frame) to save image tokens.

5

Transcript fallback

If native captions aren't available, automatically falls back to Groq Whisper API for rapid speech-to-text.

6

Context assembly

Frames and timestamped transcript are handed to the agent sequentially as vision inputs.

7

Agent answers

The agent responds grounded in what it saw and heard, with precise timestamp references.

Detail modes

One dial. Speed vs. coverage.

Control exactly how many tokens the agent spends analyzing the video.

Frequently asked questions

Does it work without an API key?
Yes. If the video has native captions (like most YouTube videos), yt-dlp extracts them directly for free. Whisper is only used as a fallback for files without captions.
What video sources does it support?
Over 400+ platforms through yt-dlp, plus local `.mp4`, `.mov`, `.mkv`, and `.webm` files.
How does frame deduplication work?
We run a fast 16Ã—16 pixel brightness delta pass over the extracted frames. If a frame is visually identical to the last one we kept, we drop it. This protects your agent's context window.
What does `--detail efficient` mean?
Instead of decoding the entire video to find scene cuts, we instruct ffmpeg to only extract I-frames (keyframes). It takes ~0.5s instead of ~20s.
Is it open source?
Yes, agent-watch is licensed under MIT and fully open source on GitHub.
